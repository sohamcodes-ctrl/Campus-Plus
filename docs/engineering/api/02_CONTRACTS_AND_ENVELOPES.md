# API Contracts & Response Envelopes

## 1. Standard Response Envelope Format

All responses generated by the Campus Plus HTTP API strictly adhere to standardized JSON envelopes.

### Success Envelope

```json
{
  "success": true,
  "data": { ... },
  "meta": {
    "correlation_id": "c1f76d49-41fa-4f51-872f-522f6e7c7a52",
    "timestamp": "2026-09-11T10:00:00.000Z"
  }
}
```

### Paginated Collection Envelope

```json
{
  "success": true,
  "data": [ ... ],
  "meta": {
    "correlation_id": "c1f76d49-41fa-4f51-872f-522f6e7c7a52",
    "timestamp": "2026-09-11T10:00:00.000Z",
    "pagination": {
      "page": 1,
      "page_size": 20,
      "total_records": 48,
      "total_pages": 3,
      "has_next": true,
      "has_prev": false
    }
  }
}
```

### Error Envelope

```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_FAILED",
    "message": "Request payload validation failed",
    "correlation_id": "c1f76d49-41fa-4f51-872f-522f6e7c7a52",
    "details": [
      {
        "field": "title",
        "message": "Title must be at least 10 characters",
        "code": "too_small"
      }
    ]
  }
}
```

## 2. Correlation Tracking & Distributed Tracing

Every HTTP response includes the `x-correlation-id` header matching `meta.correlation_id` or `error.correlation_id`.
Clients and logging utilities use this identifier to correlate presentation errors with domain audit records in `action_history`.

## 3. Authoritative HTTP Status Code Mappings

| Status Code | Semantics | Typical Domain / Application Cause |
|---|---|---|
| **200 OK** | Successful Query / Mutation | Complaint retrieved, reviewed, assigned, resolved, closed |
| **201 Created** | Entity Created | Complaint submitted via `POST /api/v1/complaints` |
| **400 Bad Request** | Schema Validation Failure | Zod payload parsing error, invalid MIME type, missing mandatory field |
| **401 Unauthorized** | Authentication Missing | Missing/invalid bearer token or session identity |
| **403 Forbidden** | Authorization Violation | BOLA/IDOR attempt, cross-department mutation, student role escalation |
| **404 Not Found** | Resource Missing | Invalid UUID or tracking code not found in database |
| **409 Conflict** | State / Concurrency Conflict | Stale `expectedVersion` (OCC), Idempotency key payload mismatch |
| **422 Unprocessable Entity** | Illegal Domain Transition | Transition not permitted by FSM transition matrix |
| **500 Internal Error** | Uncaught System Failure | Unhandled database disconnect, unexpected system fault |
